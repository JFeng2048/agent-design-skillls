# 系统提示词设计输入表

使用说明：本表是**设计输入与对齐留痕**，不是待填问卷。
原则：**能从项目、文档、线上数据里拿到的，自己填，不问用户**；第 3 部分只放必须由人拍板的业务决策，且每项都要带推荐项。

顺序固定：第 1 部分（自主调研）→ 第 2 部分（推断默认方案）→ 第 3 部分（业务决策，≤3 项带选项）。
第 3 部分空着即为「全部采用推荐方案」。
