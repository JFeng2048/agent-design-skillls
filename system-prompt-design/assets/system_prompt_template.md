# 系统提示词骨架模板

使用说明：
1. 复制本文件为交付物，删除所有 `{{}}` 占位符与本说明。
2. 严格保持分区顺序：身份 → 能力边界 → 硬约束 → 业务规则 → SOP → 输出规范 → 示例 → 安全 → 兜底。顺序即优先级。
3. 结构分工：Markdown 标题承担人读组织逻辑，XML 标签承担机器可解析的精确语义。
4. 每条细则一行、动词开头、条件在前；禁止出现“适当”“尽量”“酌情”等模糊词。
5. 全文禁止出现每次请求变化的动态字段（时间、路径、用户 ID），动态信息放入紧随其后的 user 消息。
6. 填写完成后运行 `python scripts/lint_prompt.py <文件>` 做静态体检。

## 上下文安全
